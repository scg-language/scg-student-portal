# 約束事（機能を作る前に読む）

2026-11-21 決定。**ここに書いてあるのは「決まり」だけ**。なぜそう決めたか・だれが言ったかは、ドライブ側の運用文書に置く（このリポは public）。

機能を作る人（人でもエージェントでも）は、ここに無いスキーマ・権限・記録の形を自分で作らない。要るなら止まって、リードに報告する。

## 1. 原則

- 見せる範囲は need-to-know。非常勤には強めに当てる。迷ったら広めに付けて、操作の記録で確かめる
- 先生に見せる範囲は「人」ではなく「クラス（いまいる教室）」で決める。先生とクラスの担当表は持たない
- 小テストは成績に入れない。理解度の傾向を追うためのもの。配点で採点しない（1問1点）
- 学生の画面はやさしい日本語。職員の画面（スマホ画面も）はふつうの日本語
- 回答・点数は消さない。取り消し・停止は「集計から外す」「止める」で表す

## 2. 権限は「できること」で持つ

- 各機能は「この操作ができるか」だけを聞く。役職の名前で分岐しない
- 役職は、できることの束（ひな型）。最初の束は3つ＝先生（非常勤）／常勤／情報管理者。人ごとの足し引きができる
- 束を増やすとき（事務など）は、その機能を作るときに中身を決める
- 権限を変えられるのは情報管理者だけ。変更は操作の記録に残し、承認者を1行書く
- 判定はサーバー側。画面で隠すだけにしない（直接呼んでも断る）

| できること | 先生 | 常勤 | 情報管理者 |
|---|---|---|---|
| テストを始める。自分が始めた回を閉じる・取り消す | ○ | ○ | ○ |
| 他の人が始めた回を閉じる・取り消す | × | ○ | ○ |
| 再テストの一覧（名前と対象テスト）を見る。再テストを開く | ○ | ○ | ○ |
| 回を1つ開いて、名前と点数を見る | ○ | ○ | ○ |
| 結果をまとめて見る・書き出す | × | ○ | ○ |
| 問題の登録・編集・公開・削除 | × | ○ | ○ |
| 合格の線を変える | × | ○ | ○ |
| アンケートを作る。回を始める・閉じる | × | ○ | ○ |
| アンケートの回答と提出の状況を見る | × | ○ | ○ |
| 名簿と学生の詳細を見る | × | ○ | ○ |
| パスワードを初期値に戻す | × | ○ | ○ |
| アカウントの発行・停止・再開、卒業生への切り替え | × | × | ○ |
| お知らせを作る・出す | × | ○ | ○ |
| 問題の変更の履歴を見る | × | ○ | ○ |
| 操作の記録を見る | × | × | ○ |
| 権限を変える | × | × | ○ |

- 学生＝自分の分だけ見る・受ける・答える
- 教室PC＝ログインなしで映すだけ。テストを始めるまで、教室名を大きく出す
- 先生は、回を1つずつ開けば名前と点数を見られる。複数の回をまたぐ画面には点数を出さない。書き出しは無い

## 3. 操作の記録

- **共通の表1つ**に、全機能が同じ形で書く：だれが・どの役割で・いつ・何を・どれに。機能ごとに別の表を作らない
- 残すもの＝書き換えの全部＋「学生の名前が並ぶ画面を開いた」こと
- 直せない・消せない（update / delete のポリシーを作らない）。読めるのは情報管理者だけ
- 設問の本文・回答の中身・個人の値を記録に入れない。入れるのは対象の id・件数・種類まで
- 記録に失敗しても、元の操作は止めない。ただし黙らない
- 残す期間は5年（起点は確認中。分かるまで「卒業から5年」）

## 4. アカウント

- ログインID＝学籍番号。**ハイフンなしの数字7桁だけ**を通す。入力は全角・ハイフンつきも受けて、取ってから照合する。桁の決まりは1か所に置く
- 例示・ダミーは `2604999` のように、末尾が 999 から降りる帯を使う
- アカウントの一生：在籍 → 卒業生／在籍 → 退学（停止）
  - 退学＝全部止める（ログイン不可）。回答と点数は残す
  - 卒業生＝別の役割。自分の成績・記録を読める。テストは受けない。卒業から5年ほど生かす
  - 停止・卒業した学生は、再テストの一覧から外す
- 個人の情報を消すときも、統計に使う属性（入学期・進学先・就職の結果など）は、名前と番号を外して残す
- 国籍・エージェントはポータルに持たない

## 5. 合格の線と再テスト

- 合格＝**正解率 80% 以上**。線は**テストの種類ごとに1本**（回ごとには持たない）。変えられるのは「合格の線を変える」を持つ人。変えた線は次のテストから効く（終わったテストの合否はさかのぼらない）
- テストの種類ごとに「再テストあり／なし」を持つ。漢字・まとめ＝あり。毎日の課のテスト＝なし
- 不合格が決まったら、本人の画面に再テストのお知らせを出す。合否は本人に見せる
- **再テストは自動では開かない。先生が教室で開いて、監督して、閉じる。** 同じ日には開けない（翌日以降）。閉じ忘れは、その日のうちに自動で閉じる
- 先生のスマホに「再テストの学生が◯名います」を出し、押すと実施の画面へ進む。出す場所は2つ
  - ホーム：全クラスの合計。押すとクラスごとの人数が並び、クラスを選ぶ
  - **いつものテストを閉じた直後**：そのクラスの人数。クラスはもう選んであるので、押すとそのまま開ける
- 先生は「クラス（だれが受けるか）」を選ぶ。教室とクラスを結ぶ表は持たない
- 再テストは教室の画面に映さない。先生のスマホだけで開いて、閉じる
- 再テストの時間は、元のテストと同じ分数を初めから入れておき、先生が変えられる
- 先生の一覧に出すのは、対象／受けた（合格）／まだ受けていない／また不合格。名前と対象テストだけで、点数は出さない。元のテストの日付を添える
- 受けなかった学生は、受けるまで一覧に残る。期限は作らない
- テストの日に休んだ学生は、「まだ受けていない（1回目）」として同じ一覧に入る。1回目で落ちたら、再テストの対象になる
- **再テストは1回だけ。** 再テストで落ちたら、そのまま
- 再テストの点は、最初の点とは別の記録にする（例「漢字 L1-2（再）」）。最初の点は上書きしない
- 集計：テストごとに、平均と「80% に届かなかった割合」を出す。毎日の課のテストも含む

## 6. 受験ずみのテストを直す

- 受験後も自由に直せる（設問・選択肢・正解・設問の追加と削除）。点数は提出時の数字のまま動かない
- 採点し直し・1人分の点の手直しは作らない
- 設問を足すときの番号は「いまの最大＋1」。保存の順番（正解を直してから、あふれた選択肢を消す）は変えない

## 7. データベースの決まり（従来どおり）

- 変更は `db/YYYY-MM-DD_*.sql` に置く。巻き戻し手順を書く。流す前に `python tests/test_db_migrations.py`
- 新しい表のポリシーには `to authenticated` を書く。新しい RPC には `revoke execute ... from anon` を書く
- 先に画面、後から DB。表・列・RPC が無くても、画面は「その操作だけ使えません」で動く
- 正解を学生に送らない。採点はサーバー側
- 適用・main への push は、きあの確認のあと

## 8. 受け入れ条件（触ってこう動けば完成）

| 機能 | 条件 |
|---|---|
| ログインID | ハイフンあり・全角で打っても、同じ学生としてログインできる。7桁以外は、発行のときに断られる |
| 権限 | 先生のアカウントで、2章の × の操作が画面に出ない。直接呼んでも、サーバーが断る |
| 操作の記録 | 書き換えと「名前の並ぶ画面を開いた」ことが、1行ずつ残る。情報管理者だけが読める。だれも直せず、消せない |
| 合格の線 | 漢字・まとめで 80% に届かなかった学生が不合格になる。線を変えると、次のテストから効く |
| 再テストのお知らせ | 不合格が決まると、本人の画面にお知らせが出る。合格した学生には出ない |
| 再テストの実施 | 先生のスマホに「再テストの学生が◯名います」が出る。押すと教室を選んで開ける。同じ日には開けない。閉じ忘れても、その日のうちに閉じる |
| 再テストの引き継ぎ | 受けなかった学生と、休んだ学生（1回目）が、受けるまで一覧に残る。受けたら消える。再テストで落ちた学生には2回目が出ない |
| 再テストの点 | 最初の点はそのまま残り、再テストは別の記録になる |
| 教室の画面 | テストを始めるまで、教室名が大きく出ている |
| アカウントの一生 | 退学にするとログインできない。卒業生にすると、成績は読めるがテストは受けられない。どちらも再テストの一覧から消える |
| 集計 | テストごとの平均と「80% に届かなかった割合」が見られる |

## 9. 4月のあとに本番にするもの（先に動く見本で確かめる）

本番のデータにはつながず、ダミーだけで動く見本（`*-preview.html`）を先に作り、触って詰める。

- **進学先情報**：学校を探して、HP・募集要項・オープンキャンパスの日程を見る。正本は別システムで、ポータルは公開してよい列だけを読む。「おすすめ」の印は人が付ける（自動で付けない）。志望校は学生がいつでも変えられ、3つまで入れられる。学生の希望と、職員が確認した正式な記録は分ける
- **成績ポートフォリオ**：本人が、小テストの推移・出席率・定期試験・JLPT の結果を、いつの時点の数字かと一緒に見る。ほかの学生の分は取れない。卒業生も読める。難しさの違うテストを1本の線で結ぶだけにしない
- **アルバイト情報**：書類（雇用契約書・毎月の給与明細）の提出と確認。「アルバイトなし／書類がまだ出ていない／提出免除／未入力」を別に扱う。未入力を0時間と数えない。書類は非公開の置き場。形は担当部署と詰める
